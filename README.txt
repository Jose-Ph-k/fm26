FM26 Scout AI - PWA V1

포함 기능
- iPhone/iPad Safari에서 홈 화면 추가 가능한 PWA
- 선수 스크린샷 선택 및 미리보기
- 선수 정보 입력
- 나이/CA/PA/비용 조건 기반의 1차 영입·임대·매각 판단
- 오프라인 캐시(Service Worker)

중요
- 실제 스크린샷 자동 판독 및 GPT 분석을 위해서는 API 키를 브라우저에 직접 넣지 말고
  서버 또는 서버리스 함수(예: Cloudflare Workers, Vercel Functions 등)를 중계로 사용해야 합니다.
- PWA는 HTTPS 호스팅에서 가장 안정적으로 설치됩니다.

iPhone/iPad 설치
1. HTTPS로 배포된 주소를 Safari에서 엽니다.
2. 공유 버튼 → 홈 화면에 추가.
3. 홈 화면의 FM26 Scout 아이콘으로 실행합니다.
